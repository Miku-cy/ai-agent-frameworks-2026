## 中文

### 报告安全漏洞

我们非常重视项目的安全性。如果你发现了任何安全漏洞，请按照以下步骤报告：

1. **不要创建公开的 Issue 来报告漏洞
2. 通过以下方式之一联系我们：
   - 创建一个私有 Issue（如果仓库支持）
   - 直接联系项目维护者

### 我们会如何处理

当你报告一个安全漏洞后，我们会：

1. 确认收到你的报告
2. 调查并评估漏洞的严重性
3. 尽快修复问题
4. 发布安全公告

### 支持的版本

目前，我们支持以下版本的安全更新：

| 版本 | 支持状态 |
| ---- | -------- |
| 1.x | ✅ 支持 |

## English

### Reporting a Vulnerability

We take security very seriously. If you discover a security vulnerability, please follow these steps:

1. **Do NOT create a public Issue to report vulnerabilities
2. Contact us by one of the following methods:
   - Create a private Issue (if the repository supports it)
   - Contact the project maintainers directly

### What to Expect

After you report a security vulnerability, we will:

1. Acknowledge receipt of your report
2. Investigate and assess the severity
3. Fix the issue as soon as possible
4. Release a security advisory

### Supported Versions

Currently, we support security updates for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes    |
