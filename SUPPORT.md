## 中文

### 如何获得帮助

如果你在使用本项目时有问题，可以通过以下方式获得帮助：

1. **查看文档**：首先查看我们的 [README.md](README.md) 文档
2. **搜索 Issues**：在 [Issues](../../issues) 中搜索是否已有相关问题
3. **创建新 Issue**：如果没有找到答案，请创建新 Issue

### 提问的建议

为了更好地帮助你，请在提问时：

- 使用清晰的标题
- 提供详细的描述
- 如果可能，提供复现步骤
- 说明你期望的结果

## English

### Getting Help

If you have questions while using this project, you can get help through the following ways:

1. **Check Documentation**: First check our [README.md](README.md)
2. **Search Issues**: Search in [Issues](../../issues) to see if there are related questions
3. **Create New Issue**: If you don't find an answer, create a new Issue

### Question Tips

To help us help you better, when asking questions:

- Use a clear title
- Provide a detailed description
- If possible, provide reproduction steps
- Explain your expected outcome
